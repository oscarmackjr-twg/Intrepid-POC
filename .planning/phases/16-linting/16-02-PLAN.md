**A. Install husky and lint-staged** (per D-08):

From the `frontend/` directory, run:
```bash
npm install --save-dev husky lint-staged
```

This adds `husky` and `lint-staged` to `frontend/package.json` devDependencies.

**B. Add prepare script** (per D-11):

In `frontend/package.json`, add `"prepare": "husky"` to the `scripts` block. The final scripts block should be:
```json
"scripts": {
  "dev": "vite",
  "build": "tsc -b && vite build",
  "lint": "eslint .",
  "preview": "vite preview",
  "prepare": "husky"
}
```

**C. Add lint-staged config** (per D-09, D-10):

Add a top-level `"lint-staged"` key to `frontend/package.json`:
```json
"lint-staged": {
  "*.{ts,tsx}": "eslint --fix",
  "../backend/**/*.py": "ruff check --fix"
}
```

The `../backend/**/*.py` glob navigates up from frontend/ to reach backend Python files. lint-staged passes matched file paths to the command.

Per D-09: `eslint --fix` on staged `*.ts` and `*.tsx` files.
Per D-10: `ruff check --fix` on staged `*.py` files from backend/.

**D. Initialize husky and create pre-commit hook** (per D-12):

From the repo root, run:
```bash
cd frontend && npx husky init
```

This creates `.husky/pre-commit` with a default command. Then overwrite `.husky/pre-commit` with exactly:
```
cd frontend && npx lint-staged
```

The `cd frontend` prefix is needed because git hooks run from the repo root, but lint-staged config lives in `frontend/package.json`. husky v9 uses the simplified single-line format (no shim sourcing needed).

**Important:** The `.husky/` directory is created at the repo root (where `.git/` lives), NOT inside `frontend/`. husky v9 auto-detects the `.git` directory.

If `npx husky init` creates `.husky/pre-commit` inside `frontend/.husky/` instead of repo root `.husky/`, move it: the husky `prepare` script should set `--dir` or use the default which looks for `.git`. Run `npx husky` from the frontend directory -- it will walk up to find `.git` and place `.husky/` at the repo root.

**E. Verify the hook file exists:**

Confirm `.husky/pre-commit` exists at repo root and contains `npx lint-staged`.
