**3. Create frontend/src/utils/formatKpi.ts (per D-13 through D-18):**
Export five pure functions:

- `formatUPB(value: number | null): string` — Per D-13 and D-18:
  - If `value` is null, return `"\u2013"` (en-dash)
  - If `value >= 1_000_000_000`, return `$X.XXB` (e.g., `$1.23B`) — 2 decimal places
  - If `value >= 1_000_000`, return `$X.Xm` (e.g., `$456.7m`) — 1 decimal place
  - Otherwise return `$X,XXX` with comma separators (use `toLocaleString('en-US')`)

- `formatRate(value: number | null): string` — Per D-14 and D-18:
  - If `value` is null, return `"\u2013"`
  - Return `value.toFixed(2) + "%"` (e.g., `5.25%`, `68.40%`)

- `formatWAM(value: number | null): string` — Per D-15 and D-18:
  - If `value` is null, return `"\u2013"`
  - Return `Math.round(value) + "mo"` (e.g., `84mo`)

- `formatDSCR(value: number | null): string` — Per D-16 and D-18:
  - If `value` is null, return `"\u2013"`
  - Return `value.toFixed(2) + "x"` (e.g., `1.45x`)

- `formatCount(value: number | null): string` — Per D-17 and D-18:
  - If `value` is null, return `"\u2013"`
  - Return integer with commas via `Math.round(value).toLocaleString('en-US')` (e.g., `1,234`)

Each function returns `"\u2013"` (en-dash character, not two hyphens) for null inputs.
