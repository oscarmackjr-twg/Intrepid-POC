**Component function `ReOriginationPage`:**

1. **Queries:**
   - `origination` query: `queryKey: ['re-origination-pipeline', filters]`, fetches `GET /api/re/origination-pipeline` with filter params (same pattern as RePortfolioPage concentration query). Type: `OriginationPipelineResponse`.
   - `market` query: `queryKey: ['re-market-context']` (NO filters — static key per D-10, same pattern as ReCashFlowPage line 59-65). Type: `MarketContextResponse`.

2. **Stacked bar data transformation (for ORIGIN-01, D-03):**
   Pivot `origination.data.origination_by_month` from flat rows `{year, month, property_type, loan_count, total_upb}` into Recharts stacked bar format. Each unique `YYYY-MM` becomes one data point with keys for each property type's UPB:
   ```typescript
   // Collect unique property types
   const propertyTypes = [...new Set(origination.data?.origination_by_month?.map(r => r.property_type) ?? [])]

   // Pivot: group by year-month, property_type values become keys
   const volumeByMonth = new Map<string, Record<string, number>>()
   for (const row of origination.data?.origination_by_month ?? []) {
     const key = `${row.year}-${String(row.month).padStart(2, '0')}`
     if (!volumeByMonth.has(key)) volumeByMonth.set(key, { month: key } as any)
     volumeByMonth.get(key)![row.property_type] = Number(row.total_upb)
   }
   const volumeData = [...volumeByMonth.values()]
   ```

3. **Net Origination Volume (ORIGIN-02, D-05):**
   Sum all `total_upb` from `origination.data.origination_by_month`:
   ```typescript
   const netOriginationVolume = (origination.data?.origination_by_month ?? [])
     .reduce((sum, r) => sum + Number(r.total_upb), 0)
   ```

4. **Pipeline funnel data (ORIGIN-03, D-06):**
   Use `origination.data.pipeline_funnel` directly. Render as horizontal `BarChart` with `layout="vertical"`. Each bar shows stage name on Y-axis, UPB on X-axis. Add a secondary label showing loan count per bar via custom Tooltip.

5. **Vintage data (ORIGIN-04, D-07):**
   Use `origination.data.vintage_breakdown` directly. Render as HTML table.
