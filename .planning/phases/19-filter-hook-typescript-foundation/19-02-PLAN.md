## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL params -> React components | User can manually edit URL; values rendered in select/input controls |
| Filter sidebar -> URL | User selection writes to URL via setSearchParams |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-03 | Spoofing | URL params | accept | URL params are user-editable by design; filter values are display-only strings rendered via React JSX (auto-escaped). No dangerouslySetInnerHTML used. |
| T-19-04 | Tampering | Filter select options | accept | Hardcoded option lists in the component; user can only select valid options via UI. Manual URL editing produces invalid filter values that the backend rejects (Phase 18 server-side validation). |
| T-19-05 | Information Disclosure | Filter panel visibility | accept | Filter panel is visible to all authenticated users. No sensitive data displayed — only filter controls with generic option lists. |
</threat_model>
